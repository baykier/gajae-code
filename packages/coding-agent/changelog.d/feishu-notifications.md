### Features

- Add Feishu (飞书) notification providers: a push-only group webhook (`feishu`) for one-way delivery into a custom-bot group, and a two-way enterprise app bot (`feishu-app`) that runs as a managed daemon with interactive ask cards, `/sdk` command relay, allowlisted free-form chat, and `gjc notify setup feishu|feishu-app` onboarding.
